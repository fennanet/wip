# WIP writer
WIP writer is (yet to be) screenplay software written in Rust, HTML, CSS and JS, using the Tauri framework.

## WHY ?
There isn't much of a big OSS scene when it comes to screenplay software, which is quite sad as it's pretty much essential for people trying to just write a script and not pay 300$ for software you can only use on MacOS and Windows. [read more in my blog post](https://www.fenna.net/why-is-screenplay-writing-software-so-bad/)
